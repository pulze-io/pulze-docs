With the desktop app, Dream talks to your 3D software. No more screenshot, save, upload: press **Grab viewport** and the current view is in your input.

## How it works

1. The [installer](/project-dream/getting-started/installation) puts a Project Dream plugin into each supported app.
2. Open your 3D app and the Project Dream desktop app. The app finds the running hosts on its own; **Refresh host list** if it doesn't.
3. In any image input, press the grab button for what you want.

| Button | Takes | Available in |
|---|---|---|
| **Grab viewport** | The active viewport | 3ds Max, Maya, Revit, Rhino, SketchUp, Cinema 4D, Blender |
| **Grab VFB** | The last render in the frame buffer | 3ds Max with V-Ray or Corona |
| **Grab Document** / **Grab Selection** | The open image or selection | Photoshop |

The plugin's button in your 3D app starts the desktop app or brings it to the front.

## Where to find the plugin

| App | Where |
|---|---|
| 3ds Max | **Project Dream** button in the *Pulze* toolbar category |
| Blender | 3D Viewport sidebar → **Pulze** → **Project Dream** → **Open** |
| Cinema 4D | **Extensions** menu |
| Revit | **Add-Ins** tab |
| Maya, Rhino, SketchUp | Loaded automatically; Project Dream toolbar/menu |
| Photoshop | **Plugins** → **Project Dream**. See [Photoshop](/project-dream/integrations/photoshop). |

<Tip>
Don't minimize the 3D app before grabbing: minimized windows give lower-quality grabs.
</Tip>

## Troubleshooting

- **"No hosts found":** make sure the 3D app is open and its plugin is installed. See [Plugin not installed](/project-dream/troubleshooting/plugin-not-installed).
- **Grab VFB fails:** open the V-Ray or Corona frame buffer window in 3ds Max first.
- **Grab buttons missing:** you're in the web app. Grabbing needs the desktop app.

## Web or desktop?

| | Web app | Desktop app |
|---|---|---|
| Where | [dream.pulze.io](https://dream.pulze.io) | Windows 10/11 |
| All modes, Flow Graph, Canvas | ✓ | ✓ |
| Grab viewport / VFB from 3D apps | – | ✓ |
| Grab document or selection from Photoshop | – | ✓ |
| Phones and tablets | ✓ | – |

Start in the browser. Install the desktop app when you want to pull images straight from your 3D software.

## Install the desktop app

<Steps>
  <Step title="Download">
    Press **Download App** in the web app's header, or get the installer from [pulze.io](https://www.pulze.io/products/project-dream).
  </Step>
  <Step title="Pick your apps">
    Close your 3D apps and run the installer. It finds the supported apps on your computer. Make sure the ones you use are ticked, and it installs a Project Dream plugin into each.
  </Step>
  <Step title="Sign in">
    Start Project Dream and press **Login with browser**. Finish signing in with your Pulze account in the browser tab that opens.
  </Step>
</Steps>

## Supported apps

| App | Versions |
|---|---|
| 3ds Max | 2019–2027 |
| Maya | 2022–2027 |
| Revit | 2021–2027 |
| Rhino | 7, 8 |
| SketchUp | 2021–2026 |
| Cinema 4D | 2023–2026 |
| Blender | 4.0–4.5, 5.0–5.2 |
| Photoshop | 2023–2026 (24.4 or newer) |

What each plugin does is on the [Plugins](/project-dream/integrations/plugins) page.

## Accounts

You sign in with a free **Pulze account**; create one from the sign-in screen with **Create an account**. You can also look around as a guest; Dream asks you to log in once you try to generate. New accounts can start a [7-day free trial](/project-dream/account/credits-and-licenses#free-trial).

A Canvas is a free-form board, like a whiteboard for images. Drop in renders and references, arrange them, and generate edits and upscales right next to the source. Share it with your team and work on it together, live.

## Adding things

- **Drop or paste** images anywhere.
- **Add note**, **Add text**, freehand draw, and paste links as link cards.
- **Group** items (G); hold Shift while resizing a group to scale its contents.

## Generating from an image

Select an image and the panel under it offers:

- **Edit:** write the change, set the aspect ratio, optionally **Draw mask** or **Draw on image**, and press **Generate**.
- **Upscale:** a creative upscale with amount, creativity and an optional prompt.
- **Combine into a new image:** select several images, drag to set their order, and describe how to combine them.

The result appears as a new image beside the source. Jobs also land in the target project you pick on the right.

## Working together

Choose **Share with team** on a canvas and teammates can open and edit it. Changes sync live and you see everyone's cursor with their name. Private canvases are only visible to you.

## Shortcuts

| | |
|---|---|
| V / H | Select / pan |
| N / T | Note / text |
| P | Freehand draw |
| G | Group |
| Arrows (Shift) | Nudge 1 px (10 px) |
| Double-click an image | Open in viewer |

Canvases save automatically. Canvas needs a screen at least 1024 px wide.

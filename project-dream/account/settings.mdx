Open **Settings** from the avatar menu. Use the search field to find an option.

  <img src="https://placehold.co/1424x1044?text=pd_settings" alt="Settings window with search field and sections General, Prompt assistance, MCP, Privacy, App & license, Advanced; General expanded showing Theme, Language, Start app on Home page, Use new navbar, Autoplay videos" />
</Frame>

| Section | Options |
|---|---|
| **General** | Theme (light/dark), **Language** (English, 日本語, Deutsch, Français, Español, Português, 简体中文), start on Home, new navbar style, autoplay videos |
| **Prompt assistance** | The AI service for *Describe image*, auto-apply prompt suggestions |
| **MCP** | Connect Dream to Claude. See [Claude connector](/project-dream/integrations/claude-connector). |
| **Privacy** | **Hide 3rd party models and services** (only Pulze models remain), **Confirm 3rd party job submissions** |
| **App & license** | Idle detection, release license when idle, refresh license. Desktop app: zoom, automatic updates. |
| **Advanced** | Desktop app: reload UI, restart app |

<Note>
Languages other than English are AI-translated. Model names, prompts and your content are never translated.
</Note>

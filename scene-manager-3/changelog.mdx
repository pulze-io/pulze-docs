<Update label="3.0.0 beta" description="November 10, 2026">
The first beta of Scene Manager 3.0, rebuilt from the ground up. It replaces 2.x: installing it removes the old plugin, and your 2.x setups come over when you open a scene.

**New Features:**
- 3ds Max 2021 to 2027, with V-Ray, V-Ray GPU, Corona and FStorm
- New user interface, refined and modernized
- Folders for setups: a folder's values pass down to every setup in it
- Modules for camera, resolution, output, sun, dome, lights, objects, layers, lightmix, color correction, render settings and more.
- Custom module for your own scene properties
- Setup from scene: one click turns the scene as it is now into a setup
- Tokens in output paths (setup, date, version, user and your own)
- Batch render any setups, each saved where its Output says
- Variations: pick objects, materials, textures, cameras or HDRIs and render every combination, each file named from its options
- Comments for agents: pin one on a viewport or frame buffer shot, attach object, material or light information, and an agent makes the changes
- Notes, to-dos, comments and tags on setups
- An MCP server with 36 tools, so AI agents can build setups, render and work through comments
- A REST API and a Python SDK (beta: may change before 3.0)
</Update>

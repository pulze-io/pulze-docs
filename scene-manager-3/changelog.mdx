<Update label="3.0.1 beta" description="November 16, 2026">
Render in the background, support for Chaos Vantage and a round of fixes.

**New Features:**
- Render in the background on your computer while you keep working
- Render with Chaos Vantage through V-Ray GPU's live link
- Save setups as 3ds Max files or V-Ray scenes
- Save output toggle beside the quality levels
- Batch rendering with the 3ds Max log
- Edit several table rows at once
- Keyboard shortcuts in the setup list
- Duplicate several setups at once
- Regions per setup: V-Ray and Corona frame buffer regions, 3ds Max crop
- Object ID column in the Objects module
- FStorm environment overrides
- Agents can render a quick preview and start or stop the interactive render

**Improvements:**
- The panel opens faster from 3ds Max
- Instanced lights show as one row
- Map slots open on the Material Editor's map
- The render button turns orange when a quality level is on or nothing is saved
- Layout refinements across the panel

**Fixes:**
- Applying a setup while V-Ray's IPR runs no longer reports failed values
- A camera's exposure and EV apply the first time
- An empty V-Ray raw image path no longer fails the Output
- Scenes with render elements of a missing renderer open without errors
</Update>

<Update label="3.0.0 beta" description="November 10, 2026">
The first beta of Scene Manager 3.0, rebuilt from the ground up. It replaces 2.x: installing it removes the old plugin, and your 2.x setups come over when you open a scene.

**New Features:**
- 3ds Max 2021 to 2027, with V-Ray, V-Ray GPU, Corona and FStorm
- New user interface, refined and modernized
- Folders for setups: a folder's values pass down to every setup in it
- Modules for camera, resolution, output, sun, dome, lights, objects, layers, lightmix, color correction, render settings and more.
- Custom module for your own scene properties
- Setup from scene: one click turns the scene as it is now into a setup
- Tokens in output paths (setup, date, version, user and your own)
- Batch render any setups, each saved where its Output says
- Variations: pick objects, materials, textures, cameras or HDRIs and render every combination, each file named from its options
- Comments for agents: pin one on a viewport or frame buffer shot, attach object, material or light information, and an agent makes the changes
- Notes, to-dos, comments and tags on setups
- An MCP server with 36 tools, so AI agents can build setups, render and work through comments
- A REST API and a Python SDK (beta: may change before 3.0)
</Update>

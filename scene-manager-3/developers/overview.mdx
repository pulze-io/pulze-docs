Scene Manager 3 runs a small service on your computer. The panel in 3ds Max talks to it, and so can your scripts and your AI assistant. The API covers setups, folders, modules, batch renders, variations and scene comments.

## The model

- A **setup** is a saved state of the scene: camera, lighting, resolution, output and so on.
- A setup's values live in **modules**. A module off in a setup leaves that part of the scene as it is.
- Setups can sit in **folders**. A folder's values go down to its setups.
- **Activating** a setup writes its values into the open scene. A **batch render** activates and renders each setup in turn.

Scene Manager never creates scene content for you. It records what the scene already has and switches between states of it.

## Before you start

- **3ds Max only**, for now.
- **Scene Manager must be running.** Open it from 3ds Max. The service answers on `http://127.0.0.1:45710`. Set `SCENEMANAGER_PORT` to change the port.
- **It is local.** The service listens on `127.0.0.1` only. There is no API key: being on the computer is the proof.
- **A Scene Manager licence** on this computer is needed for every call except `GET /health`. Without one, calls answer **402**.

One operation has one name everywhere. `GET /setups` is `listSetups` in the [API reference](/scene-manager-3/api-reference/introduction) and `scene.setups.list_setups()` in Python.

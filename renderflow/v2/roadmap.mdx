<Note>
Everything on this page is planned work, not a commitment. Items can change, move to another quarter or be dropped, and a quarter here is not a release date. For what has already shipped, see the [changelog](/renderflow/v2/changelog).
</Note>

<Update label="2026 Q4" description="October to December 2026">
- Agentic Jobs — run AI models across your farm, on repetitive tasks, like cleanup, automation and rendering
- AI Wrangler — an agent that watches jobs on the farm and acts on the ones that go wrong
- Houdini PDG and TOPs — submit TOP networks and their work items as RenderFlow jobs
- Repository-less operation — run a farm without a shared repository folder
- Multi-language support — the interface in languages other than English
- Directory integration — user, group and role management through your directory, with SSO and SCIM
- Multi-instance and GPU affinity — several render instances per machine, each pinned to its own GPU
</Update>

<Update label="2027 Q1" description="January to March 2027">
- Cloud rendering — connect Azure, GCP, AWS or a private render farm
- Mobile app — follow the farm and your jobs from a phone
- Software deployment — install and update applications and plugins across the farm from one place
- Secondary fallback server and database — a standby server and database that take over when the primary is unavailable
- Support for OpenJD — run jobs described with the Open Job Description specification
</Update>

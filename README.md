# Pulze documentation

The source for [docs.pulze.io](https://docs.pulze.io): guides and reference for RenderFlow, Project Dream and Scene Manager.

**Reading the docs? Go to [docs.pulze.io](https://docs.pulze.io).** This repository is what the site is built from.

## What's inside

| Product | What it covers | Start here |
|---|---|---|
| **RenderFlow** | Render farm manager for your own machines and your own Azure or AWS account. Setup, submitting from 26 applications, guides, scripting, and the REST API, SDKs, CLI and MCP server | [Quick start](https://docs.pulze.io/renderflow/getting-started/quick-start) |
| **Project Dream** | Image and video AI fine-tuned for visualization specialists and architects. Models and changelog | [Overview](https://docs.pulze.io/project-dream) |
| **Scene Manager** | Scene states and batch rendering for 3ds Max. Installation, setups, modules and scripting | [Overview](https://docs.pulze.io/scene-manager) |

Popular pages:

- [Supported applications](https://docs.pulze.io/renderflow/getting-started/supported-apps): versions, render engines and platforms for every application RenderFlow submits from
- [Moving from RenderFlow 1 or Pulze Render Manager](https://docs.pulze.io/renderflow/getting-started/migrating)
- [Unreal Engine and Perforce](https://docs.pulze.io/renderflow/guides/unreal-and-perforce)
- [Developer overview](https://docs.pulze.io/renderflow/developers/overview): the REST API, SDKs, CLI, live updates and webhooks
- [REST API](https://docs.pulze.io/renderflow/developers/rest-api) and the [API reference](https://docs.pulze.io/renderflow/api-reference/introduction)
- [Cookbook](https://docs.pulze.io/renderflow/developers/cookbook): submit and wait, requeue failures, pull frames, archive nightly

## For AI assistants

The docs are written to be read by agents as well as people:

- **MCP server:** add `https://docs.pulze.io/mcp` to Claude or any MCP client to search the docs from the chat
- **Plain text:** [llms.txt](https://docs.pulze.io/llms.txt) is the index, and [llms-full.txt](https://docs.pulze.io/llms-full.txt) is every page in one file
- **Markdown pages:** add `.md` to any page path, for example [quick-start.md](https://docs.pulze.io/renderflow/getting-started/quick-start.md)
- **Skill:** [skill.md](https://docs.pulze.io/skill.md) tells an agent where to look for what

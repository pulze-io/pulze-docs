---
title: "Masks"
description: "How LayerWise turns multimatte and luminance passes into layer masks, and how nametags name them."
---

Selective adjustments are the core of arch-viz post-production: warm up the wood, darken the glass, lift the plants. LayerWise builds the masks for that from your matte passes, and puts them on groups you can drop adjustment layers into.

There are two kinds of mask source:

- **Multimatte** elements (*RGB masks*): each of the red, green and blue channels holds one object selection, so one file makes up to **three** masks. Examples: V-Ray MultiMatteElement, Corona CMasking_Mask, FStorm MultiMatte.
- **Luma mask** elements: the brightness of the whole image is the mask. Examples: Alpha, ZDepth, ReflectionFilter.

Which elements are which is set in [Render elements](/layerwise/render-elements).

## Nametags

A multimatte's three channels need names. You give them in the file name with **nametags**: a wildcard character (`#` by default) followed by a name, in the part of the file name after a dot.

```
cam01.MultiMatteElement.#Wood#Glass#Stone.png
                        └─R─┘└─G──┘└─B──┘
```

The first tag names the red channel, the second the green, the third the blue. This file makes three masks: `#Wood`, `#Glass` and `#Stone`.

In most renderers you set this by naming the multimatte render element itself, for example naming the V-Ray MultiMatte element `MultiMatteElement.#Wood#Glass#Stone`.

- **Missing tags** get a default name from the file name and the channel, such as `MultiMatteElement_R`. Default names have no wildcard.
- **Fewer channels:** you can turn off the red, green or blue channel in [Settings](/layerwise/settings#masks). The other channels keep their tags (turning off green doesn't move the blue tag to green).
- **Another wildcard:** if `#` clashes with your naming, choose `$`, `&`, `@` or `%` in [Settings](/layerwise/settings#masks).

## Luma masks

A luma mask element makes a single mask named `[LUMA]` followed by the element name, for example `[LUMA]Alpha` or `[LUMA]ZDepth`. White in the pass is visible, black is hidden.

## Where the masks go

Each mask has a name, such as `#Wood` or `[LUMA]Alpha`. LayerWise then:

1. **Puts it on every layer or group with exactly that name**, anywhere in the document. Existing masks on those layers are replaced.
2. **Creates a new group with that name** if none exists, at the top of the group the matte layer is in, with the mask on it.
3. **Saves it as an alpha channel** with the same name in the Channels panel, so you can load it as a selection any time.

A mask that would be completely empty hides everything, so an object that's no longer in the shot doesn't leave a stray selection.

<Tip>
Put your selective adjustments **inside** the `#Wood`-style groups. Next time you [update the renders](/layerwise/workflows/update-renders), the group masks are regenerated from the new multimatte, and your adjustments follow the objects even if the camera or the model changed.
</Tip>

You can also name any existing layer or group yourself, for example `#Plants`, and render a multimatte with a `#Plants` tag. LayerWise will find it and mask it.

## When masks are made

| Where | What happens |
|---|---|
| [Create new document](/layerwise/workflows/create-document) with **Extract layer masks** on | Masks are made right after each matte is placed. Groups of the template with matching names get them; missing ones are created. Matte layers are hidden afterwards. |
| [Update renders](/layerwise/workflows/update-renders) | **Update existing layer masks** regenerates the masks of existing targets; **Create new layer masks** adds groups for new tags. Both run after any resize. |
| [Extract layer masks](/layerwise/tools#extract-layer-masks) tool | Makes masks from the selected multimatte layers, any time. |

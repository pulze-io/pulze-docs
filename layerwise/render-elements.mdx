LayerWise recognizes files and layers by their render element names (see [How it works](/layerwise/how-it-works#render-elements-and-name-matching)). The **Render elements** screen is where you check and change that list for each engine.

Open it from the menu, the shortcut on Home, [Tools](/layerwise/tools) → **Manage render elements**, or [Settings](/layerwise/settings#masks).

## The flags

| Flag | Meaning |
|---|---|
| **Import all** ★ | Import every file of this element, not just one (for example one LightSelect per light). |
| **RGB masks** | A multimatte: the red, green and blue channels become [three masks](/layerwise/masks#nametags). |
| **Luma mask** | The brightness becomes a [`[LUMA]` mask](/layerwise/masks#luma-masks). |

## Add an element

Type the name in **New element name**, set its flags and press **+ Add**. The name must be unique and is case-sensitive. It's matched as part of file and layer names, so `Wood_Mask` recognizes `cam01.Wood_Mask.png`.

Add an element when:

- your renders use a pass LayerWise doesn't know (a custom V-Ray ExtraTex, a renamed element),
- a file shows up under **These files matched no element**,
- a template says an element is **Not recognized**.

Elements you added have a **×** to delete them. Built-in elements can't be deleted, but you can change their flags.

## Save or restore

Changes apply when you press **Save**. **Cancel** throws them away, and **Restore defaults** brings back the original list (it also applies on Save).
